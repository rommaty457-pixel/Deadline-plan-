# Deadline Planner Ultimate (Android-friendly web app)

เว็บจัดการเดตไลน์ที่มีปฏิทินรายเดือน, งาน/สถานะ/ความสำคัญ, โปรเจกต์, เปอร์เซ็นต์ความคืบหน้า, ค้นหา/กรอง, ธีมมืด และ browser notifications

## สำคัญ: วิธีจัดเก็บข้อมูล
- หากยังไม่เชื่อม Supabase ข้อมูลจะเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนี้
- หากต้องการซิงก์ออนไลน์ข้ามอุปกรณ์ ให้ตั้งค่า Supabase ตามขั้นตอนด้านล่าง แล้วเชื่อมจากแอป
- การแจ้งเตือนในเว็บทำงานได้เมื่อเว็บเปิดอยู่/ทำงานอยู่ในเบราว์เซอร์เป็นหลัก เว็บ static นี้ไม่สามารถรับประกัน push notification เมื่อปิดเบราว์เซอร์ Android ทั้งหมดได้

## 1) เผยแพร่เว็บฟรีด้วย GitHub Pages (มือถือ Android)
1. แตกไฟล์ ZIP แล้วเข้า GitHub ใน Chrome
2. เปิด repository ใหม่ที่ `https://github.com/new` ตั้งชื่อ `deadline-planner` เลือก Public แล้วกด Create repository
3. ใน repo กด **Add file → Upload files** แล้วอัปโหลด `index.html` (ไฟล์หลัก) และ `README.md` จากโฟลเดอร์นี้ กด **Commit changes**
4. ไปที่ **Settings → Pages**
5. ใน **Build and deployment** เลือก **Deploy from a branch**, branch `main`, folder `/(root)` แล้วกด Save
6. รอสักครู่แล้วเปิด URL ที่ GitHub Pages แสดง (มักเป็น `https://ชื่อบัญชี.github.io/deadline-planner/`)
7. ใน Chrome Android กดเมนู ⋮ → **Add to Home screen** หรือ **Install app** เพื่อเพิ่มทางลัด

## 2) ตั้งค่าฐานข้อมูลออนไลน์ด้วย Supabase
1. เปิด `https://supabase.com/` แล้วสร้างโปรเจกต์ใหม่ เก็บรหัสฐานข้อมูลไว้ส่วนตัว
2. เข้า **SQL Editor → New query** แล้ววาง SQL จาก `supabase.sql` ใน ZIP จากนั้นกด Run
3. เข้า **Project Settings → API** (หรือ Connect) คัดลอก **Project URL** และ **anon/public key** เท่านั้น
4. เปิดเว็บ Deadline Planner ที่เผยแพร่แล้ว เลื่อนลงส่วน **ข้อมูลออนไลน์** แล้วกรอก URL กับ anon/public key จากนั้นกด **เชื่อมต่อ**
5. กรอกอีเมลที่เข้าถึงได้ ระบบจะส่ง Magic Link ให้เปิดอีเมลและแตะลิงก์ เมื่อกลับเข้าเว็บให้กดเชื่อมต่ออีกครั้ง
6. หลังเข้าสู่ระบบ สร้าง/แก้ไขงานเพื่อทดสอบการซิงก์

## 3) ความปลอดภัย
- ห้ามนำ `service_role` key มาใส่ในเว็บเด็ดขาด
- SQL ตั้ง Row Level Security (RLS) ให้แต่ละบัญชีเห็นเฉพาะแถวที่ `user_id` ของตัวเองตรงกับผู้ใช้ที่เข้าสู่ระบบ
- อย่าใช้ข้อมูลลับหรือข้อมูลสำคัญเกินจำเป็นในโน้ตงาน
- ก่อนเริ่มใช้จริงกับข้อมูลสำคัญ ควรทดสอบสร้าง/แก้ไข/ลบงานและตรวจสอบการซิงก์ระหว่างอุปกรณ์

## ข้อจำกัดที่ควรรู้
- นี่เป็นเว็บ static ที่ใช้ Supabase เป็นบริการหลังบ้าน ไม่ใช่เซิร์ฟเวอร์ที่โฮสต์โดยผู้สร้างไฟล์
- การแจ้งเตือน browser ต้องอนุญาตสิทธิ์และมักต้องเปิดเว็บไว้ เว็บนี้ไม่มีระบบ push notification เบื้องหลังเมื่อปิดเว็บ
- ไฟล์ `index.html` โหลด Supabase JS ผ่าน CDN ต้องเชื่อมอินเทอร์เน็ต
